## Hallazgo TDD

La primera aceptación del instalador mostró que Windows PowerShell no convierte automáticamente un código no cero de un proceso nativo en una excepción. El script continuó y mostró un mensaje final incorrecto después de fallar `venv`.

Se agregaron comprobaciones de `$LASTEXITCODE` después de cada comando externo. La repetición confirmó que:

- una creación fallida detiene inmediatamente la instalación;
- no se imprime un falso éxito;
- una instalación sin restricciones completa todas las etapas.
